# Screenshots

Diese Bilder zeigen die auf einem echten Android-Gerät getestete Oberfläche von Foto-Upload 1.9.0. Vor einer Veröffentlichung neuer Screenshots dürfen keine Passwörter, Cookies oder privaten Serveradressen sichtbar sein.

- `einstellungen.png`: Serveradresse, QR-Scanner, Verbindungstest und Profilverwaltung
- `navigation.png`: dauerhaft erreichbare untere Navigation
- `erster-start.png`: Android-Benachrichtigungsfreigabe beim ersten Start
