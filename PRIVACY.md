# Datenschutzerklärung für Foto-Upload

Foto-Upload verbindet sich ausschließlich mit der vom Benutzer eingetragenen Serveradresse. Die über GitHub verteilte APK prüft zusätzlich GitHub auf neue App-Versionen; der Google-Play-Build verwendet dafür ausschließlich Google Play. Fotos und Videos werden nur an den ausgewählten Foto-Upload-Server übertragen. Die App betreibt keinen eigenen Analysedienst, zeigt keine Werbung und verkauft keine Daten.

Serveradressen und Profilnamen werden lokal auf dem Gerät gespeichert. Beim Scannen eines QR-Codes verarbeitet Google Play Services den Code auf dem Gerät. Für Uploads erhält die App nur Zugriff auf ausdrücklich ausgewählte Medien. Standortdaten werden von der App nicht separat abgefragt; vorhandene Metadaten bleiben Bestandteil der ausgewählten Originaldatei.

Der Betreiber des jeweils eingetragenen Servers ist für dessen Speicherung, Zugriffsschutz und Löschung verantwortlich. Fragen und Löschanfragen sind an diesen Betreiber zu richten. Für Fragen zur App kann ein Issue im öffentlichen GitHub-Repository erstellt werden.
